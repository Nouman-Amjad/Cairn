# cairn-mcp-kit

Shared scaffolding for Cairn MCP servers: identity, OPA authorization, and server-side result capping.

Part of [Cairn](https://github.com/Nouman-Amjad/cairn), an agentic
incident-analysis copilot.

```bash
uvx cairn-mcp-kit --stdio    # run against any MCP client
```

See the main repository for architecture, security model and
deployment.
