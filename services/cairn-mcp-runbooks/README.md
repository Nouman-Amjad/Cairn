# cairn-mcp-runbooks

MCP server for hybrid runbook search and past-incident recall.

Part of [Cairn](https://github.com/Nouman-Amjad/cairn), an agentic
incident-analysis copilot.

```bash
uvx cairn-mcp-runbooks --stdio    # run against any MCP client
```

See the main repository for architecture, security model and
deployment.
