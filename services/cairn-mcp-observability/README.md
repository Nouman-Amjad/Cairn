# cairn-mcp-observability

MCP server exposing metrics, logs, traces and the deploy timeline.

Part of [Cairn](https://github.com/Nouman-Amjad/cairn), an agentic
incident-analysis copilot.

```bash
uvx cairn-mcp-observability --stdio    # run against any MCP client
```

See the main repository for architecture, security model and
deployment.
